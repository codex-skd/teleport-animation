<h2>v0.0.0-beta.37 - ViewArea runtime method fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Chunk rendering during animation</strong>: <code>ViewArea.repositionCamera</code> now uses <code>SectionPos</code> instead of <code>(double, double)</code> via reflection, matching the production runtime signature. The <code>(double, double)</code> overload only exists in NeoForge dev environment.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>LevelRendererMixin.repositionViewArea()</code> — tries <code>(double, double)</code> first (dev), then falls back to <code>(SectionPos)</code> (runtime).</li>
</ul>
