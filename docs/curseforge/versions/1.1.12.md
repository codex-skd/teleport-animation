<h2>v1.1.12 - Fix player appearing below waystone on arrival</h2>

<h3>Fix</h3>
<ul>
<li><strong>Player appearing below waystone on arrival</strong>: the `getFeetPos()` method in `TeleportTransitionController` was returning the player's eye position (`player.getY()`) instead of the actual feet position (`player.getY() - player.getEyeHeight()`). This caused all distance calculations, arrival detection, and camera synchronization to be offset by approximately 1.62 blocks upward, sometimes causing the character to appear in the block beneath the destination waystone. Fixed to use the actual feet position.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>TeleportTransitionController.getFeetPos()</code> now returns `new Vec3(player.getX(), player.getY() - player.getEyeHeight(), player.getZ())` with null safety check.</li>
<li>Affects: travel distance calculation, arrival target detection, normal chunk handoff animation, and client-server synchronization.</li>
</ul>
