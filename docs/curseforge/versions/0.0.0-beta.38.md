<h2>v0.0.0-beta.38 - ViewArea chunk discard fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Chunks disappearing in blocks during zoom-out</strong>: <code>ViewArea.repositionCamera</code> now targets the <strong>player's position</strong> instead of the animation camera position. This prevents the ViewArea from discarding built sections at the player's location while the camera zooms out.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>LevelRendererMixin.repositionViewArea()</code> — repositions ViewArea to <code>SectionPos.of(player.getX(), 0, player.getZ())</code> instead of <code>SectionPos.of(cameraPos)</code>.</li>
<li>Removed verbose per-frame diagnostic logging from render loop.</li>
<li>Fixed remaining <code>GTP</code> log prefixes to <code>TA</code> in <code>TeleportTransitionController.java</code>.</li>
</ul>
