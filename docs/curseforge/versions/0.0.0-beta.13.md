## Teleport Animation 0.0.0-beta.13

### Changes since beta.12

- Added EntityMixin to intercept teleport methods on Entity (parent class) instead of only ServerPlayer
- Fixed camera/HUD state not being restored after crash or disconnect
- Camera and HUD are now force-reset on the first game tick to prevent third-person/HUD-hidden on join
- Teleport(TeleportTransition) mixin added for Minecraft 26.1.2 compatibility

### Known issues

- Teleport animation may still not trigger for some teleport sources
