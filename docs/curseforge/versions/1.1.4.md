<h2>Version 1.1.4 — Teleport Phase 2 Refinements</h2>

<h3>What's New</h3>

<ul>
  <li><strong>Smart Distance-Based Rendering</strong>: The mod now detects when waystones are within render distance and optimizes the camera animation accordingly.
  <ul>
    <li><strong>Nearby Waystones</strong>: Smooth camera drag with no fade-to-black overlay for a seamless experience when teleporting short distances.</li>
    <li><strong>Distant Waystones</strong>: Full cinematic fade-to-black transition with two-phase camera drag (20-block approach + destination arrival) for dramatic long-distance teleports.</li>
  </ul></li>
  <li><strong>Eliminated Double Flicker</strong>: Fixed an issue where the HUD overlay and travel blackout were rendering simultaneously at the start of phase 2, causing visual stuttering.</li>
</ul>

<h3>Improvements</h3>

<ul>
  <li>Travel phase now respects render distance settings for optimal performance and visual coherence.</li>
  <li>Smoother animation transitions between phases with better fade timing.</li>
  <li>HUD overlay no longer overlaps with travel blackout effect.</li>
</ul>

<h3>Technical Details</h3>

<ul>
  <li><code>calculateTravelTicks()</code> now detects nearby waystones (distance &lt; renderDistance × 16 blocks).</li>
  <li><code>getTravelBlackoutIntensity()</code> returns 0.0 for nearby teleports, skipping the fade-to-black effect.</li>
  <li><code>getHudFadeOverlayIntensity()</code> suppresses the HUD overlay during travel phase to prevent double-flicker.</li>
</ul>
