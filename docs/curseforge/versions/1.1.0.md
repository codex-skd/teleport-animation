<h2>v1.1.0 - Config overhaul &amp; travel flicker fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Floor flicker during the top-down travel flight</strong>: the transition was forcing a full rebuild of all compiled terrain geometry every time the camera crossed a chunk section while flying, which discarded and recompiled the ground mid-flight. The camera now keeps a lightweight terrain sync during travel instead.</li>
</ul>

<h3>Feature</h3>
<ul>
<li><strong>Config now uses NeoForge's native config system</strong>: settings are stored in <code>config/teleport_animation-client.toml</code> instead of a custom <code>.properties</code> file, auto-created on first launch and editable from the <strong>Configured</strong> mod (or any other NeoForge config screen provider).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>TeleportConfig</code> rebuilt on top of <code>ModConfigSpec</code>; the same public getters/setters are preserved so no other code needed changes.</li>
<li>Removed dead code left over from a removed custom config-screen (layout/widget/text persistence) and the legacy migration from the old "Grand Teleport" fork's config files, which no longer applies to the new format.</li>
</ul>

<h3>Notes</h3>
<blockquote>If you edited the old <code>teleport_animation.properties</code> file by hand, those values are not carried over automatically — reapply them in the new <code>teleport_animation-client.toml</code> (or via Configured) after updating.</blockquote>
