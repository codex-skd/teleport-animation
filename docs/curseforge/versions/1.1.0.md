<h2>Teleport Animation v1.1.0</h2>
<h3>Bug Fixes (ported from 26.2 fix line)</h3>
<ul>
<li><strong>Server crash on external teleport:</strong> Removed client-only config checks from the server-side transition logic. This prevented an <code>IllegalStateException</code> when Waystones triggered teleport on external events.</li>
<li><strong>Floor flicker during top-down travel:</strong> Replaced heavy terrain geometry rebuilds mid-flight with lightweight Sodium terrain updates. Added a fade-to-black overlay during travel and arrival chunk holding to wait for destination chunks before descent.</li>
<li><strong>Nearby-waystone slide + flicker:</strong> Waystones within render distance now use a smooth horizontal slide animation instead of the full travel animation, with faster travel ticks and no camera shake.</li>
<li><strong>Fall-through-floor at destination:</strong> Arrival position now targets the walk surface (Y+1) instead of the raw block Y. Fixed feet position calculation to use true feet height instead of eye height.</li>
<li><strong>Underground spawn on long trips:</strong> Destination waystone chunks and cardinal neighbours are now force-loaded before teleport, preventing landing underground when chunks weren't loaded.</li>
</ul>
