<h2>v0.0.0-beta.41 - ViewArea camera section fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Chunks disappearing during zoom-out</strong>: ViewArea is now repositioned to the <strong>animation camera's position</strong> (not the player's), and <code>lastCameraSectionX/Y/Z</code> is set to match the camera's section. This prevents vanilla from overriding the ViewArea position while ensuring terrain sections are loaded around where the camera actually is.</li>
<li><strong>Player model invisible</strong>: <code>shouldHideLocalPlayerModel()</code> now always returns <code>false</code>. The player character is always visible during the animation.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>LevelRendererMixin</code> — added <code>repositionViewArea()</code> and <code>getViewArea()</code>, updated <code>maskPlayerChunkReposition()</code> to use camera position for section tracking while keeping player position for prevCam fields.</li>
</ul>
