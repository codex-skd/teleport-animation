<h2>Teleport Animation v1.2.0</h2>
<h3>Changed</h3>
<ul>
<li><strong>Native config system:</strong> The hand-rolled <code>config/teleport_animation.properties</code> file has been replaced with a native NeoForge <code>ModConfigSpec</code>. The mod now generates <code>config/teleport_animation-client.toml</code> automatically on first launch and shows up as editable in Configured / any TOML config editor. This brings the 1.21.1 branch in line with the 26.2 config backend.</li>
<li><strong>Sound settings are now visible:</strong> <code>customSoundsEnabled</code>, <code>minecraftSoundVolume</code> and <code>customSoundVolume</code> live in the <code>[sounds]</code> section of the generated TOML. (There is still no per-sound picker &ndash; "custom sounds" means the mod's own bundled set; override the <code>.ogg</code> files via a resource pack to use your own.)</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>Orphaned config-GUI layout layer</strong> (~490 lines of dead code): the <code>configLayout</code> / <code>configWidget</code> / <code>configText</code> persistence machinery carried over from Grand Teleport had no callers on this branch and has been dropped.</li>
<li><strong>Legacy <code>.properties</code> migration</strong> (<code>grand_teleport.properties</code> / <code>gtalike_teleport.properties</code>). Old <code>.properties</code> values are not migrated &ndash; re-set any customised options in the new TOML.</li>
</ul>

<hr>

<p><em>Config backend port from the 26.2 branch. The public <code>TeleportConfig</code> API is unchanged, so teleport/zoom/waystone behaviour is identical to 1.1.0. <code>compileJava</code> + <code>build</code> pass; not run in-game (dev env lacks Balm/Waystones).</em></p>
