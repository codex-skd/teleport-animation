# v0.0.0-beta.1 — Initial NeoForge port

First beta release of Grand Teleport for NeoForge 1.21.1.

## Added

- Port completo desde Grand Teleport Forge 1.20.1 a NeoForge 1.21.1 (21.1.238)
- Transición cinematográfica tipo GTA al teletransportarse
- 3 etapas de zoom configurables (in/out) por dimensión (Overworld, Nether, End)
- Sistema de sonidos personalizados (7 efectos OGG)
- Comandos `/ta` y `/tpanimation` para controlar el efecto
- Integración con servidor: sistema de delayed teleport con ACK
- Integración con Waystones (teleport y warp plates)
- Compatibilidad con Sodium, Iris, Bobby, Distant Horizons, Voxy, JourneyMap, Leawind's Third Person
- Bloqueo de input durante la transición (mouse, teclado)
- Supresión de efectos de pantalla y HUD durante la animación
- Control de cámara, fog, frustum y level renderer via mixins
- Más de 20 mixins portados desde la versión Forge original
