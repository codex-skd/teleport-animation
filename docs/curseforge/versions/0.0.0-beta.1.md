<h2>v0.0.0-beta.1 - Initial 1.20.1 port</h2>

<h3>Added</h3>
<ul>
<li><strong>Minecraft 1.20.1 support</strong>: full port of Teleport Animation from the 1.21.1 NeoForge branch to NeoForge 1.20.1 (legacyforge / Forge-compatible), preserving all mixins, config options, and mod compatibility (Waystones, JourneyMap, Sodium, Iris, Distant Horizons, Bobby, Voxy, Leawind's Third Person).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Ported all mixin classes and Java mappings from Minecraft 1.21.1 to Minecraft 1.20.1 (Mojang mappings via Parchment 2023.09.03).</li>
<li>Rewrote networking from the modern <code>StreamCodec</code>/<code>RegisterPayloadHandlersEvent</code> API (1.20.4+) to the legacy <code>SimpleChannel</code>/<code>NetworkRegistry</code> API used on NeoForge 1.20.1.</li>
<li>Replaced <code>DeltaTracker</code> partial-tick handling (introduced in 1.21) with the plain <code>float partialTick</code> parameters used on 1.20.1.</li>
<li>Adjusted all mod-loader API imports from the modern <code>net.neoforged.*</code> namespace to the <code>net.minecraftforge.*</code> namespace used by NeoForge 1.20.1 (legacyforge).</li>
</ul>

<h3>Notes</h3>
<blockquote>This is a beta release of the initial 1.20.1 port. Please report any issues with mixin compatibility or specific mod integrations.</blockquote>
