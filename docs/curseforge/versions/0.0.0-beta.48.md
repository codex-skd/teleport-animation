<h2>v0.0.0-beta.48 - Fix crash on startup</h2>

<h3>Fix</h3>
<ul>
<li><strong>Game crashed on launch</strong>: <code>FrustumMixin</code> used an invalid <code>@ModifyVariable</code> index on the non-static <code>Frustum.prepare</code> method, which Mixin rejected at class-load time, crashing the game before the main menu.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>FrustumMixin.teleportAnimation$modifyCamX/Y/Z</code> — switched from <code>index</code> (raw local-variable-table slot, where slot 0 is <code>this</code> on an instance method) to <code>ordinal</code> (argument position) in <code>@ModifyVariable</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>0.0.0-beta.47 crashes on startup and should not be used. Please update to this version.</blockquote>
