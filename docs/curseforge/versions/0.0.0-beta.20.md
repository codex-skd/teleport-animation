<h2>v0.0.0-beta.20 - Waystones-Only Animation + Client Mixins Restored</h2>

<h3>Change</h3>
<ul>
<li><strong>Scope reduced</strong>: animation now only plays for Waystones teleports &mdash; <code>/tp</code> and other teleport methods are ignored.</li>
<li><strong>Client mixins restored</strong>: CameraMixin, KeyboardInputMixin, MouseHandlerMixin and other client mixins re-enabled for proper visual animation.</li>
<li><strong>Waystones mixins registered</strong>: Waystones and Warp Plate mixins now load correctly via mixins.json.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><code>ClientPacketListenerMixin</code>, <code>ConnectionMixin</code>, <code>JourneyMapClientNetworkDispatcherMixin</code> &mdash; no more /tp or packet interception.</li>
<li><code>TeleportCommandMatcher</code>, <code>TeleportDestinationParser</code> &mdash; command parsing no longer needed.</li>
<li><code>EntityTeleportEvent</code> handler &mdash; server-side event interception removed.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><code>tryDelayExternalTeleport()</code> now always returns <code>false</code> &mdash; generic teleport interception disabled.</li>
<li>Waystones handler uses <code>source=3</code> to bypass external teleport config check.</li>
</ul>
