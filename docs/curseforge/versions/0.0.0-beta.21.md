<h1>v0.0.0-beta.21</h1>
<h2>Changes</h2>
<ul>
<li><strong>Fixed MC 26.1.2 compatibility:</strong> Updated all client mixins for Minecraft 26.1.2 rendering pipeline changes (Camera.setup → extractRenderState, LevelRenderer.renderLevel new signature, EntityRenderDispatcher.shouldRender, etc.)</li>
<li><strong>Camera override:</strong> Injects into <code>Camera.extractRenderState()</code> instead of removed <code>setup()</code>, writes directly to <code>CameraRenderState</code> for reliable render pipeline override</li>
<li><strong>Entity rendering:</strong> Uses <code>EntityRenderDispatcher.shouldRender()</code> instead of removed <code>render()</code> for hiding local player during body camera</li>
<li><strong>Screen effects:</strong> Updated <code>renderScreenEffect()</code> signature to match MC 26.1.2 instance method</li>
<li><strong>Server mixins:</strong> Updated EntityMixin and ServerPlayerMixin with correct imports and disabled dead code paths</li>
<li><strong>Keyboard/Mouse input:</strong> Fixed method signatures for <code>tick()</code>, <code>turnPlayer()</code>, <code>onButton()</code></li>
<li><strong>All remap=false:</strong> Uses direct method names with <code>remap=false</code> on all @Inject targets to fix Mixin AP obfuscation mapping errors in MC 26.1.2</li>
</ul>
