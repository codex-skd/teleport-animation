<h2>v1.0.0 - First Stable Release</h2>

<h3>Added</h3>
<ul>
<li>First stable release — all beta features polished and production-ready</li>
<li>Full cinematic teleport animation system with 3 configurable zoom stages</li>
<li>Custom sound system (7 OGG effects)</li>
<li>Server-side delayed teleport with ACK system</li>
<li>Configuration screen with layout editor</li>
<li>Persistent settings via property system</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Waystones 21.1.37 compatibility</strong>: added <code>tryTeleportAsync</code> interception — the async method is now the primary teleport path; animation triggers correctly</li>
<li>Removed dead mixins targeting removed Waystones API (<code>PlayerWaystoneManager.tryTeleport</code>, <code>IWaystoneTeleportContext</code>)</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Project structure aligned with WORKFLOW_GENERIC conventions (<code>libs/</code>, <code>templates/</code> path, <code>.gitignore</code>)</li>
<li>Animations now trigger exclusively on Waystones teleports (<code>/tp</code> commands excluded)</li>
<li>All Grand Teleport branding removed — fully rebranded to <strong>Teleport Animation</strong></li>
</ul>
