<h2>v0.0.0-beta.39 - Always show player model</h2>

<h3>Fix</h3>
<ul>
<li><strong>Player model invisible during animation</strong>: Removed the <code>shouldHideLocalPlayerModel</code> logic entirely. The player character is now always visible in third-person during the zoom-out animation, letting you see your character from above.</li>
<li>The camera is forced to third-person mode for the duration of the animation.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>TeleportTransitionController.shouldHideLocalPlayerModel()</code> now returns <code>false</code> unconditionally.</li>
</ul>
