<h2>v0.0.0-beta.2 - Fix wrong loader coordinates</h2>

<h3>Fix</h3>
<ul>
<li><strong>Wrong NeoForge version resolved at build time</strong>: the build was pinned to <code>net.minecraftforge:forge</code> (the original, unrelated Forge project, which advanced its own numbering up to 47.4.x), instead of <code>net.neoforged:forge</code> (NeoForge's own legacy-compat branch, which stayed on 47.1.x for Minecraft 1.20.1). This made the published beta.1 JAR require Forge 47.4.22, a version that does not exist for actual NeoForge installs, breaking mod loading with a "requires forge 47.4.22 or above" error.</li>
<li><strong><code>ResourceLocation.fromNamespaceAndPath</code> does not exist on 1.20.1</strong>: this method was introduced in Minecraft 1.21+. Replaced with the 1.20.1 constructor <code>new ResourceLocation(namespace, path)</code> in <code>TeleportSounds</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>build.gradle</code>: <code>legacyForge { version = "..." }</code> → <code>legacyForge { enable { neoForgeVersion = "..." } }</code>, which resolves the correct <code>net.neoforged:forge</code> coordinates.</li>
<li><code>gradle.properties</code>: <code>forge_version</code>/<code>loader_version</code> corrected to <code>47.1.99</code> (NeoForge's actual 1.20.1 legacy branch).</li>
</ul>

<h3>Notes</h3>
<blockquote>If you installed beta.1 and it failed to load with a "requires forge 47.4.22 or above" error, update to this version. Waystones on 1.20.1 also requires <strong>Balm 7.2.0+</strong> as a separate dependency — make sure it is installed alongside this mod and Waystones.</blockquote>
