<h2>v0.0.0-beta.49 - Rework camera override timing for terrain/player rendering</h2>

<h3>Fix</h3>
<ul>
<li><strong>Terrain and player rendering during teleport animation</strong>: reworked how the transition camera position is applied so it lands before vanilla builds the frame's cull frustum and repositions chunk sections, instead of after.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CameraMixin</code> — moved the camera override from <code>Camera.extractRenderState</code> (TAIL) to <code>Camera.update</code> (right after <code>alignWithEntity</code>), so the transition camera position is set before frustum/view/projection setup for the frame.</li>
<li><code>LevelRendererMixin</code> — removed the reflection-based <code>lastCameraSectionX/Y/Z</code> masking hack; vanilla's own section repositioning now works correctly since the real camera position is already correct earlier in the frame.</li>
<li><code>EntityRendererMixin</code> — force the local player entity visible during the animation instead of relying on frustum timing.</li>
<li>Removed <code>FrustumMixin</code> (no longer needed).</li>
</ul>
