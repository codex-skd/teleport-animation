<h2>v1.1.2 - Server config access fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Server crash on external teleport events</strong>: the server was attempting to access client-side config values during network packet processing, causing <code>IllegalStateException: Cannot get config value before config is loaded</code>. This error occurred when mods like Waystones triggered teleports through the external teleport handler. The server-side validation has been removed; the client validates these settings before sending packets to the server.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Removed <code>isEffectEnabled()</code> and <code>isWarpPlateTransitionsEnabled()</code> checks from <code>TeleportServer.shouldStartServerTransition()</code>. These are client-side config checks that belong on the client, not the server. The server now only validates player state (alive, not spectator) and networking capabilities.</li>
</ul>
