<h2>v1.0.2 - Fix teleport animation flickering for nearby waystones</h2>

<h3>Fix</h3>
<ul>
<li>Eliminated flickering in Phase 2 (displacement) when teleporting to nearby waystones by implementing smooth camera pre-displacement with fade transition</li>
<li>Added <code>slideFrame()</code> for smooth camera slides (no fade-to-black) on nearby waystone teleports</li>
<li>Implemented <code>travelFrame()</code> with elegant fade-to-black drags for distant waystones</li>
<li>Automatic detection of nearby waystones based on player render distance</li>
<li>Optimized terrain refresh with cheap Sodium updates instead of full geometry rebuilds during travel phase</li>
<li>Added <code>getTravelBlackoutIntensity()</code> for smooth fade-to-black transitions</li>
<li>Ported blackout rendering to <code>TeleportStepEffectRenderer</code></li>
</ul>

<h3>Details</h3>
<p>The teleport animation now uses two different strategies based on waystone distance:</p>
<ul>
<li><strong>Nearby waystones</strong> (within render distance): Smooth camera slide across terrain with no fade — keeps the path visible and flicker-free</li>
<li><strong>Distant waystones</strong>: Elegant fade-to-black with camera drag movements at start and end of travel</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Ported camera pre-displacement logic from v26.2 to v26.1.2</li>
<li>20-block pre-displacement distance with 9-tick fade windows</li>
<li>Terrain chunk handoff delay support to avoid flicker while chunks stream in</li>
</ul>
