<h2>v0.0.0-beta.40 - Chunk rendering + workflow update</h2>

<h3>Fix</h3>
<ul>
<li><strong>Chunks disappearing (blue sky only)</strong>: Removed the <code>repositionCamera</code> call from the <code>renderLevel</code> inject. Vanilla chunk setup runs before <code>renderLevel</code>, so the inject was too late and only caused chunk discard. The <code>maskPlayerChunkReposition</code> now handles preventing view re-centering.</li>
<li><strong>Player model invisible during animation</strong>: <code>shouldHideLocalPlayerModel()</code> now always returns <code>false</code>. The player character is always visible in third-person during the animation.</li>
</ul>

<h3>Docs</h3>
<ul>
<li>Updated WORKFLOW from v1.2.7 to v1.4.0: added "Organización en el workspace" section with <code>&lt;mod_id&gt;/&lt;mc-version&gt;/</code> structure, added <code>temp/</code> directory, added historial de versiones.</li>
</ul>
